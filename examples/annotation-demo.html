🎨 Annotation Reference

Every WebMCP annotation combination mapped to a sample tool. Each card shows the annotation values visible to the MCP client. Hover over registerTool calls in the console for the full definition.

readOnlyHint
Tool only reads state; safe to auto-invoke.
destructiveHint
Tool may destroy or overwrite data irreversibly.
idempotentHint
Repeated calls with same args produce the same result.
openWorldHint
Tool may interact with external services or the real world.
false
Annotation explicitly set to false, overriding any default.
